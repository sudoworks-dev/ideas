# 📁 Project Context

Place background materials here that SDE should consider during
goal-setting (`/sde-goal`) and planning (`/sde-refine`).

## What belongs here?
* Existing specifications or PRDs
* Meeting notes or stakeholder feedback
* Reference architectures or design sketches
* Competitor analysis or market research
* Migration notes from legacy systems

## How is it used?
SDE workflows scan this folder for inspiration and constraints.
Files here are **read-only context** — SDE will not modify them.
